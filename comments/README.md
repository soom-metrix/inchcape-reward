# Comentarios de revisión

`comments.json` guarda los comentarios de los revisores (copia de la base de datos del artefacto de claude.ai).
Además, cada comentario puede guardarse como **Issue** de este repositorio con el enlace «Save to GitHub as an issue» del panel de comentarios (requiere cuenta de GitHub).

Para actualizar la copia: pedir a Claude que vuelque la colección `comments` del artefacto a este archivo y la suba al repositorio.
